# MBBS Tracker (Android)
1. Edit `www/firebase-config.js` with your Firebase web config (optional; without it the app is offline-only).
2. Push to GitHub (branch `main`).
3. Open the repo → Actions → "Build Android APK" → open the latest run → download the `MBBS-Tracker-apk` artifact.
4. Unzip, copy `app-debug.apk` to your phone and install (allow "Install unknown apps").
